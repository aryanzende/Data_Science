## How to Run

1. Install Python 3.10 or above.
2. Open the assignment notebook in Jupyter Notebook, Jupyter Lab, VS Code, or Google Colab.
3. Keep the dataset file in the same folder as the notebook.
4. Install required libraries using:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn scipy statsmodels openpyxl mlxtend xgboost lightgbm nltk textblob ppscore
```

For ANN assignment, install TensorFlow separately if required:

```bash
pip install tensorflow
```

5. Run the notebook cells from top to bottom.
